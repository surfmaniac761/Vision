Privacy Policy for Vision Bot
Effective Date: August 10, 2026

1. Introduction
This Privacy Policy outlines how the Vision Discord Bot ("the Bot", "we", "our") collects, uses, and protects the data of users ("you", "your") within Discord servers where the Bot is installed. By using the Bot, you consent to the data practices described in this policy.

2. Data We Collect
To provide its services, the Bot collects and stores specific pieces of information. This includes:

Discord User IDs: Used to track user activity, statistics, leaderboards, and moderation actions.

Discord Server (Guild) IDs and Channel IDs: Used to route messages and manage automated channel configurations.

Message Content: The Bot reads message content to execute commands. Specific message content may be stored when executing logging/moderation commands or when interacting with the Bot's automated responder features.

Server Roles and Nicknames: Used to establish hierarchies and assign user positions within the Bot's interactive features.

3. How We Use Your Data
The data collected is used strictly for the operational functionality of the Bot:

Service Functionality: To provide core bot features, including user coordination, group management, and automated role assignments.

Moderation & Tracking: To maintain a permanent ledger of server rules, user statistics, and administrative actions.

Interactive Features: To process user prompts and generate automated text or image-based responses.

4. Third-Party Data Sharing
The Bot does not sell your personal data. However, to provide certain generative features, specific message content (such as user prompts) and image attachments sent directly to the Bot may be temporarily transmitted to secure, third-party API providers. These transmissions are used exclusively to generate the requested response. We do not use your message content to train our own models.

5. Data Storage and Security
Data is stored securely off-platform. We implement reasonable, industry-standard security measures to protect against unauthorized access, alteration, disclosure, or destruction of the data we collect and store.

6. Data Retention and Deletion
Data related to user statistics, leaderboards, and moderation history is kept indefinitely to maintain server integrity, unless removal is requested. Temporary session data is automatically purged by the Bot's routine background tasks.

Your Rights: If you wish to have your data permanently deleted from the Bot's database, you may contact a server administrator to process a data deletion request.

7. Changes to This Policy
We may update this Privacy Policy from time to time to reflect changes in our practices or for other operational, legal, or regulatory reasons. The "Effective Date" at the top will be updated accordingly.
